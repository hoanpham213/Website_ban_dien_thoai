# PhoneStore - Website bán điện thoại (Giai đoạn 1)

Website tĩnh viết bằng HTML, CSS, JavaScript thuần. Dữ liệu sản phẩm, giá và thông tin cửa hàng chỉ là minh họa.

## Chạy website
Mở thư mục trong VS Code, bấm chuột phải vào `index.html` > **Open with Live Server** (hoặc mở trực tiếp `index.html` bằng trình duyệt).

## Trạng thái
- Đã có: header, banner, thương hiệu, 8 sản phẩm, ưu đãi, footer, responsive.
- Chưa triển khai: tìm kiếm, lọc, chi tiết sản phẩm, giỏ hàng, đặt hàng, quản trị.
